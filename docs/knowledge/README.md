# Knowledge base

Background notes for this project: the concepts the check-in agent rests on (SIP and RTP,
codecs and sample rates, AudioSocket framing, VAD, turn-taking, escalation), written from
first principles so a decision can be reviewed, and explained, without reconstructing the
theory first.

Each note is written for a ticket on the wayfinder map and links that ticket in its preamble.
Notes follow `.claude/skills/knowledge-note/SKILL.md`.

Notes explain concepts. They do not decide the project's direction — that happens on the
issue tracker.
